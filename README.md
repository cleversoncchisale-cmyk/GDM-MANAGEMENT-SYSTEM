# GDM Management System

A professional Firebase-style web application for managing Good Deeds Ministries operations, with authentication, dashboard data, and live notifications.

## Structure
- index.html
- style.css
- firebase.js
- scripts/auth.js
- scripts/firestore.js
- scripts/dashboard.js
- scripts/ministries.js
- scripts/notifications.js
- gdm-dashboard/overview/overview.html
- gdm-dashboard/ministries/ministries.html
- gdm-dashboard/members/members.html

## Run locally
Open index.html in a browser.

## Firebase setup
Replace the placeholder Firebase config in firebase.js with your own project credentials to connect to Firebase Auth and Firestore.
